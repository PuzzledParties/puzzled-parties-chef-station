# 0001 Use GitHub As The Project Home

## Status

Accepted

## Context

Chef Station is becoming more than a single wiring diagram. It will include hardware, firmware, build notes, diagrams, and multiple interactive features.

## Decision

Use the public GitHub repository `PuzzledParties/puzzled-parties-chef-station` as the source of truth. Track tasks in Issues, changes in branches and Pull Requests, and design choices in decision records.

## Consequences

- Collaborators can clone one repo and see the current project state.
- Build context lives with the assets and code.
- Pull Requests give each change a place for review notes, test results, and discussion.
